# Agropecuaria

## Descripción

**Agropecuaria** es un sistema desarrollado en Python que permite gestionar y generar documentos académicos de manera digital para las carreras del área agropecuaria. Su objetivo principal es optimizar el tiempo de elaboración, organización y almacenamiento de información, reduciendo el uso de documentos físicos y facilitando la administración de prácticas, laboratorios e informes.

## Características

- Registro y gestión de prácticas y laboratorios.
- Generación automática de documentos PDF.
- Almacenamiento y consulta de registros.
- Interfaz gráfica intuitiva y fácil de utilizar.
- Organización eficiente de la información académica.
- Reducción del tiempo en la creación de documentación.

## Objetivo

Brindar una solución digital que facilite la elaboración y administración de documentos académicos, mejorando la eficiencia, organización y accesibilidad de la información para docentes y estudiantes.

## Tecnologías utilizadas

- Python
- CustomTkinter
- PostgreSQL
- ReportLab (Generación de PDF)
- Pillow (Procesamiento de imágenes)

## Beneficios

- Disminuye el tiempo de elaboración de documentos.
- Reduce errores en el registro de información.
- Centraliza la gestión de prácticas y laboratorios.
- Facilita el acceso y almacenamiento de los documentos generados.
- Contribuye a la digitalización de los procesos académicos.
